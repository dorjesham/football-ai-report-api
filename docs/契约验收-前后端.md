# 契约验收（C 端 + 管理端）

## 自动化

```bash
npm run ci:contract-routes   # 公开 GET smoke
npm run ci:health-e2e        # /health
```

## 管理端（React）

- 构建：`npm run build:admin`
- 部署后先验 **`GET /health`**（200），再访问 `https://{API_HOST}/admin/`（需先 `npm run prisma:seed` 与管理员账号）
- API 前缀：`/admin/api/*`（JWT + ADMIN 角色）

## 数据初始化

```bash
CONFIRM_DB_NUKE=yes npm run db:nuke-rebuild   # 全库重置 + seed 目录
# 登录管理端 → 一键入库 → full_initial
```
