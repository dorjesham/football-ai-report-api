# 比赛数据管线运维说明

## 环境

- **和风天气**：`QWEATHER_BASE_URL` 须为控制台专属 Host（`https://*.qweatherapi.com`），`QWEATHER_API_KEY` 与 `QWEATHER_CREDENTIAL_ID` 为同一项目凭据；改后需重启。
- **API-Football**：`API_FOOTBALL_API_KEY`（Sealos 环境变量，改后需重启）
- **日配额**：`API_FOOTBALL_DAILY_QUOTA=7200` + Redis（键 `football:af:quota:YYYY-MM-DD`）；Admin `GET /admin/api-football/quota`
- **Cron 总开关**：`ENABLE_CRON_SYNC=true`（见 `.env.example`）
- **AF-only**：`ENABLE_FOOTBALL_DATA=false`；赛程/积分榜 Cron 走 AF ingest；`ENABLE_MATCH_FD_LIVE_POLL=true` 仅控 AF 近窗轮询
- **生产**：`ENABLE_FOOTBALL_FEED_PUBLIC=false`（C 端勿调 `/football-feed`）；`RANKINGS_DEFAULT_SOURCE=db`
- 可选：`AUTO_INTEL_CRON_MODE=full`、`AF_LIVE_FACTS_INTERVAL_SEC=90`、`AF_LIVE_FACTS_MAX_PER_TICK=4`
- **赛中增强**（零新采购）：`ENABLE_AF_LIVE_PLAYERS_CRON`、`ENABLE_LIVE_STANDINGS_TICK`、`ENABLE_LIVE_COMMENTARY_LLM=false`（默认关）
- Admin 一键：`POST /admin/api/ingest/bundles/live_match_enrich/run`（对当前 LIVE 场次同步 events/statistics + 球员统计，不跑 intel-full）
- **管理端 UI**：`/admin/` → **运维总览**（赛中 Cron 状态、手动 tick、健康度表）/ **一键入库** →「同步进行中比赛的赛中数据」/ **比赛** → LIVE 行「同步赛中数据」

## 部署说明（2026-05-19）

- 含 **赛中增强** 与可选 **`ENABLE_LIVE_COMMENTARY_LLM`** 的后端须部署 **已拆分 `DeepseekModule`** 的镜像（修复 `MatchLiveModule` ↔ `AiReportModule` 循环依赖）；旧镜像（如 v1.1.5）可能启动失败：`AiReportModule imports[1] is undefined`。
- 部署后先验 **`GET /health` 200**，再打开管理端 `/admin/` 或执行 `live_match_enrich`。
- `ENABLE_LIVE_COMMENTARY_LLM=true` 另需有效 **`DEEPSEEK_API_KEY`**（或 mock 模式）；与 C 端字段合约无关。

## 赛程入库

1. Admin 或 `api-football-ingest`：五大联赛 `seed-comp-pl` / `pd` / `sa` / `bl1` / `fl1`
2. 欧战：`seed-comp-cl` / `el` / `uecl`
3. 确认 `DataProviderMapping` 与 AF `league` id 已对齐（seed 已写入）

## 单场 enrich

- 后台：`POST /admin/matches/:id/pipeline/intel-full`
- 或管理页「整场管线」

## 批量（即将开赛）

### 一键补全近 10 天未开赛详情（推荐）

管理端 **运维总览** 或 **一键入库** →「补全近10天未开赛详情」，或：

```http
POST /admin/api/ingest/bundles/scheduled_pre_match_bootstrap/run
Authorization: Bearer <ADMIN_JWT>
Content-Type: application/json

{
  "lookaheadDays": 10,
  "batchSize": 20,
  "maxRounds": 50,
  "skipAiReport": false
}
```

每场顺序：AF 赛前快照（带 phase）→ T24/T1 赔率 → `intel-full`（含 AI）→ 清 `pre-match` 缓存。覆盖查询：`GET /admin/api/matches/scheduled-bootstrap/coverage?lookaheadDays=10`。

### CLI 单场批量（旧）

```bash
# 预览
DRY_RUN=1 npx ts-node scripts/batch-pipeline-upcoming.ts

# 执行（默认五大联赛、未来 14 天、最多 30 场，每场间隔 3s）
COMPETITION_IDS=seed-comp-pl,seed-comp-pd DAYS=14 LIMIT=30 npx ts-node scripts/batch-pipeline-upcoming.ts
```

验收：任选真实 `matchId`，`GET /matches/:id/analysis-preview` 中 `tactics.items`、`playerIntelligence.items` 非空；`pre-match` 含 `narrative` 或结构化块。

## 球员名单 / 头像

```bash
SEASON=2025 CODES=PL,PD,SA,BL1,FL1,CL,EL npx ts-node scripts/sync-league-squads.ts
```

身价优先 `profile.apiFootball.seasons[*].marketValueEuro`；榜单见 `GET /rankings/players?source=db&metric=fantasyPrice`。

## 历史 FD 场次迁移

```bash
npx ts-node scripts/migrate-fd-matches-to-af.ts --dry-run --limit=20
npx ts-node scripts/migrate-fd-matches-to-af.ts --limit=50
```

失败行输出 CSV，需在 Admin 手工对齐。

## 清理历史演示场

```bash
npx ts-node scripts/cleanup-admin-showcase-match.ts
```

联调/生产各环境部署后执行一次；`prisma db seed` 不再创建 `seed-match-admin-showcase`。
